# DevPilot AI

An AI-powered developer workspace that helps developers understand, review, and document code repositories using Large Language Models (LLMs).

## Features

- Authentication
- GitHub Repository Import
- AI Chat with Repository (RAG)
- AI Code Review
- Documentation Generator
- Docker Deployment

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- PostgreSQL

### AI
- LangChain
- Gemini
- ChromaDB
